# Product Requirements Document

## Vision
Build an open-source research discovery platform prioritizing discovery, exploration, learning, and personalization.

## Core outcomes
- Users continuously discover valuable papers they would not find via traditional search.
- Recommendations are explainable and balanced (70/20/10 relevance-adjacent-serendipity).
- Users can learn from and organize papers in a project-centric library.

## MVP features
- Personalized + themed feeds
- Explainable recommendations
- Keyword + semantic search
- Paper page with legal-access resolution
- Bookmarks/collections/notes/tags/saved searches
- Local-model summaries via Ollama
